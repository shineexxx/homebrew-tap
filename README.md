# shineexxx/tap

Homebrew tap for [Shark](https://github.com/shineexxx/shark) — a native macOS
file converter and video downloader.

```bash
brew tap shineexxx/tap
brew install --cask --no-quarantine shark
```

This installs the app into `/Applications`, links the `shark` command and
registers its manual page, so `man shark` works straight away.
